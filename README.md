# job-posting-insight
招聘 JD 小洞察器：Pandas 统计 + LLM 摘要。

## 项目目标
统计央企/国企/银行/券商数据岗 JD 的技能要求分布，回答“这类岗位最看重什么技能”。

## 数据
- `data/jd_sample.csv`：16 条真实 JD（央企/国企/银行/券商，北京/深圳/广州等）
- 来源：招聘官网、国聘平台，含 2027 校招 + 往届 JD
- 字段：id, company, title, city, education, jd_text

## 方法
1. Pandas 读入 + 清洗 `jd_text`
2. 关键词匹配 7 个技能：SQL / Python / 统计 / 机器学习 / Spark / ETL / 数据可视化
3. 输出：每条 JD 命中表、技能频次、未命中 JD 列表

## 核心结论
- **SQL 最高频（9/16，56%）**，Python 次之（8/16，50%），统计第三（6/16，38%）
- 机器学习 3 条、Spark 2 条，ETL / 数据可视化各 1 条
- 同公司不同岗位技能密度差异大（中国移动两条 JD：一条 7 项全中，一条仅 2 项）

## 方法论反思
3 条 JD 关键词 0 命中，分属三类：
- **无技能描述型**（建设银行通用岗）：JD 不写具体技能，关键词法有盲区
- **软要求型**（中汽研）：全文为学习/沟通能力，不适合技能统计
- **专业导向型**（成都银行）：用专业名替代技能名，关键词表需补充专业术语
## LLM 语义抽取验证（针对 0 命中样本）
为验证关键词法是否漏掉了隐藏技能，我们将 3 条 0 命中 JD 输入给大模型（Gemini）做语义抽取，结果发现：
- 建设银行通用岗：仅抽出“英语”，证实该岗未写具体数据技能，偏向学历与英语门槛。
- 中汽研技术研发岗：抽出“沟通能力、文字功底”等软技能，证实其为非硬核技术岗。
- 成都银行数据岗：仅限专业名称，无具体技能要求。

**结论**：关键词法的“0 命中”并非漏报，而是真实反映了部分央企/银行岗位 JD“重学历专业、轻具体技能”的特征。这要求我们在求职时，对这类岗位的准备重点应放在笔试和综合素质上，而非死磕 SQL/Python。

→ 结论：关键词法适合粗筛，**语义级抽取需接入 LLM**（下一步）。

## 局限性说明
- **样本量小**（16 条），结论为探索性。
- **选择偏差**：数据为人工从招聘网站收集，倾向于收录含技术关键词的 JD，
  可能导致 SQL/Python 等技能频率被高估。绝对频率不代表市场真实分布，
  仅用于“技能相对排序”和“方法论对比”。
- **来源混合**：含 2027 校招与往届 JD，未做年份分层。
